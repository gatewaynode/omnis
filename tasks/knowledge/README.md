# Knowledge index

Durable working knowledge that used to be re-stated in every `tasks/CONTINUITY.md`. Read this
index after `/catchup`, then only the files the next task needs. `PRD.md` and `ARCHITECTURE.md`
stay the source of truth for what the game is and how it is shaped; these files record how the
work is done and where things are.

| File | Read it when |
|---|---|
| `agreements.md` | Before any commit, plan, or vision-document edit: the standing working agreements and the commit recipe |
| `verification.md` | Before a commit: the gate, Sentrux, the pinned numbers, replays and rebaselines, screen dumps, measurement |
| `code-map.md` | Before touching code: where each system lives across the crates, by name |
| `horizons.md` | Before planning a milestone: everything deferred, with the milestone it waits for and dated re-audits |

Related, elsewhere: `tasks/LESSONS.md` (corrections and the rules they produced), `tasks/TODO.md`
(the build order and every milestone review), `tasks/plans/` (saved plans for deferred work),
`ARCHITECTURE.md` §4.5 (the "as built" paragraphs per milestone).
