## Sim facts the app consumes (built, tested)
- `World.mode: Mode::{Explore, Encounter(EncounterState), Combat(CombatState)}` (no `Copy`); `Mode::kind() -> ModeKind`. `EncounterState { source: EncounterSource::{Fixed(u16), Random}, stacks: Vec<Stack { monster, initial, hp: Vec<i32> }>, disposition, retreat: Position }`. `CombatState { encounter, order: Vec<Initiative { actor, total, dex }>, current: u8, round, surprised: Surprise, dodging: Vec<CharacterId>, gold }`; `front_stacks(data)`, `is_front`, `current_actor()`, `outcome()`. `omnis_sim::combat::{start, weapon_for, monster_front_stacks, run_dc}` are pub; `combat::state::{can_fight, is_dead}` pub.
- `Command::Encounter(EncounterChoice::{Attack, Bribe, Hide, Run})` (words `fight bribe hide run`), `Command::Combat(CombatCommand::{Attack{stack}, Dodge, Exchange{with}, Run})` (words `attack`, `attack-N`, `dodge`, `swap-N`, `flee`). Rejections: `NotYourTurn, NoSuchStack, StackDead, OutOfReach, NeedsRangedWeapon, NoSuchMember, SameMember, CannotAfford{cost,gold}, Rule(RuleError)`; `WrongMode` for exploration commands in a fight and vice versa.
- Events (integers and traces only): `EncounterCheck{roll, chance, fired}` (every step on a map with a table; silent in the UI), `EncounterStarted{source, stacks: Vec<(MonsterId,u8)>, disposition, counts, stealth: Option<Roll>, perception, noticed}`, `Check{actor, kind: Stealth|Hide|Run|Flee, roll: Option<Roll>, dc, success}`, `Bribed{cost}`, `CombatStarted{surprised}`, `Initiative{order: Vec<(ActorRef,i64)>, rolls}`, `RoundStarted{round}`, `Turn{actor}`, `Waited{actor}`, `Dodging{actor}`, `Exchanged{a,b}`, `AttackResolved{attacker, target, roll: Roll, ac, hit, crit}`, `Damage{target, kind, rolls, raw, amount, adjust}`, `Down{target}`, `Wounded{member, failures}`, `DeathSave{member, roll, result, successes, failures}`, `Condition{target, condition, applied}`, `Death{target, gold: Option<RollTrace>}`, `CombatEnded{outcome: Victory|Fled|Defeat, xp, gold, fallen}`. `ActorRef::{Member(CharacterId), Stack(u8), Monster{stack, index}}`. `Roll { trace, mode, face, modifier, proficiency, total }`; `RollTrace` displays as `1d20 on combat: [17] = 17`.
- `combat.get` → `CombatView { phase: ModeKind, source, disposition, stacks: Vec<StackView { index, monster, name (text key), initial, hp, ac, front, alive, reachable }>, retreat, round, current: Option<ActorRef>, order, surprised, dodging, gold, front_row, monster_front_stacks }`; `omnis_sim::combat_view(world, data)`. `reachable` is computed for the acting member (false in the Encounter phase).
- When the party is not noticed (monster Stealth ≥ best passive Perception) the sim goes straight to `Mode::Combat` with `Surprise::Party`: the app never sees an Encounter mode for a surprised party. Every applied command still ends with `Visible`, so `viewport::redraw` fires on every fight command. `Status.mode` is a `ModeKind`. `MemberView` has `down`, `dead`, `death_saves`.
- Test dungeon (`packs/test/data/maps/dungeon.ron`): goblins×3 + rats×2 Hostile once at (3, 8); skeletons×2 Wary (comes back) at (9, 8); rats×3 Friendly once at (15, 8); random table 3% per step; the meadow's table is 0%. Walk from the dungeon start (1,0,S): forward ×5, turn left, forward ×2, turn right, use, forward ×3. `common::walk_to_goblins()` and `common::play()` (fights whatever interrupts) in the sim tests; the golden fight script is built by running it (`fight()` in `save_and_replay.rs`).
- Rules (`packs/base/data/rules/combat.ron`): slots `attack.total/hit/crit`, `damage.total/adjusted`, `initiative`, `monster.hit_points` (SRD average), `bribe.cost`, `encounter.random`; values `monster_front_stacks 2`, `death_save_dc 10`, `combat_round_minutes 1`; table `run_dc [15,12,10,0]`. A pack without `encounter.random` gets the plain comparison. Condition ids by name: `omnis_rules::condition_id(data, "dead"|"unconscious")`.

## App design for steps 8–14 (from the approved plan and the design pass; not yet code)
- **New Bevy-free files**: `combat_menu.rs` (`StackView`-like `CombatView`/`EncounterView` built from `World`+`Data` each frame, `CombatMenu { cursor, target, message }` with `sync` (target clamped to living stacks) and `key` → `CombatIntent::{Command(CombatCommand), Pause}`; `EncounterMenu { cursor, message }` → `EncounterIntent::{Choice, Pause}` with `bribe_label`/`bribe_allowed`; `DefeatMenu` → `Load | QuitToTitle`; `redraws(&Event)`; `menu::cycle` made `pub(crate)`), `combat_text.rs` (`Names`, `Line { long ≤ 52, short ≤ 39 }`, `batch_lines(events, names)`: one arm per event, `AttackResolved` + following `Damage` merged, e.g. `Goblin hits Brenna for 5 (1d20+4: [17] = 21 vs AC 16)`; `EncounterCheck` and monster `Turn`s silent), `combat_screen.rs` (painters), `actors.rs` (silhouette geometry shared by the sprite layer and the UI frame). Bevy: `combat.rs` `CombatPlugin` (`follow_mode`, `combat_keys`, `roll_log`). Import direction stays `combat → ui`, never `ui → combat`; `actors` imports only `layout` and `plan::DrawOp`.
- **Layout** (viewport 40×16 cells, `cell(c, r) = (1 + 6c, 8r)`): row 0 header `COMBAT  Round n` / `ENCOUNTER` left, `{actor:.10} to act` / disposition right; rows 1–4 stack rows `{count:>2} {name:<20} {front|back|slain}` = 29 cells (`WidgetId::Stack(i)`, `Kind::Choice`, selected = target, dead rows disabled); rows 5–10 clear (the 3D view and silhouettes show through; row 10 carries count digits centred on each silhouette); row 11 action row `Attack` c1 `Dodge` c9 `Exchange` c16 `Run` c26 / `Attack` c1 `Bribe {cost}g|free` c9 `Hide` c22 `Run` c28 (`WidgetId::Action(i)`, `Kind::Button`); rows 12–15 a four-line roll log tail (newest TEXT, older DIM, `fit(line, 39)`). Panel fills `(0,0,240,40)` and `(0,88,240,47)` only: `Menu::covers_viewport()` false for Encounter/Combat; `compose` fills the whole viewport for other menus (`screen.rs:111`).
- **Silhouettes**: slots `[0, −1, +1, −2, +2]` tiles by stack index; front stacks at z 3 (camera floor line y 88 = the clear window's bottom), back stacks at z 4.5 (feet y 81, lighter dark); heights by `Size` Tiny 0.3, Small 0.55, Medium 0.8, Large 1.0, Huge 1.25, Gargantuan 1.5 tile (12–61 px), width half the height; four `Paint::Fill` rects (head 0.5w×0.25h, body w×0.5h, two legs 0.35w bottom quarter), colour (20,14,24) front / (36,30,44) back; spawned at z0 2.0 via `spawn_ops::<ViewportSprite>` after the scene; `redraw` also triggers on `redraws(event)` (EncounterStarted, Death, CombatEnded, Bribed, Check). `Camera::new((240,135))`: `sx(x,z) = 120 + 121.5·x/z`, `sy(h,z) = 67.5 − (h−0.5)·121.5/z`.
- **Keys**: Up/Down actions, Left/Right target over living stacks, Enter confirm, `a d e r` hotkeys, Escape opens the pause overlay (Resume returns via `follow_mode`). Exchange partner = the `Selected` band row (message when none or self). Attack on an unreachable stack shows why before the sim rejects. Encounter: Left/Right and Up/Down both cycle the four choices; Bribe disabled when unaffordable (message `Not enough gold: {cost} needed, {gold} carried`), `Bribe free` when Friendly.
- **Defeat**: `PlayState::Defeat` (a state, so keys/pad/screen gate like Paused); `screens::modal(frame, rect, title, lines, buttons, cursor)` (~45 lines) at `(48,32,144,64)` "The party has fallen" with `Load last save` (`ShellCommand::Load`; stays in Defeat until `WorldReplaced`; a failed load leaves the modal with the notice) and `Quit to title` (remove `SimWorld`, `AppState::MainMenu`).
- **Wiring**: `PlayState::{CreateParty, Explore, Encounter, Combat, Paused, Defeat}` + `PlayState::for_mode(&Mode)`; `follow_mode` in `SimSet::Publish`: (1) any `CombatEnded{Defeat}` this frame → `Defeat`; (2) in Explore/Encounter/Combat set `for_mode(world.mode)` when it differs; (3) in Defeat on `WorldReplaced` → `for_mode`.
