## Facts the next work will lean on
- `canvas.rs`: `Layout { width, core, wing, band }` from `Layout::for_width(width)` (`const fn`): `centred = (width − 960)/2`; wide iff `centred >= WING` (63 cells = 378 px, so width ≥ 1716): `core = (centred, 0)`, `wing = (centred − 378, 0, 378, 540)`, `band = (wing.x, 540, 1658, 180)`; else `core = ((width − 1280)/2, 0)`, no wing, `band = (core.x, 540, 1280, 180)`. `NARROW = for_width(1280)` reproduces every constant. Methods: `canvas()`, `shift(rect)`, `viewport()`, `right_column()`, `minimap()`, `overlay_clip()`, `band_cell(c, r)`, `band_columns()`, `log_column()` (0 wide, 63 narrow), `log_cells()`, `roster_origin()` (wing cell (1,1) wide, band caption row narrow), `slot_origin(slot)`. The band's row/column constants (`BAND_ROW0 68`, `MESSAGE_ROW 0`, `CAPTION_ROW 2`, `FIRST_MEMBER_ROW 3`, `MEMBER_ROWS 6`, `LOG_COLUMN 63`, `LOG_ROWS 18`, `HELP_ROW 21`, `ROWS_USED 22`, `BAND_COLUMNS 212`, `ROSTER_CELLS 61`, `LOG_CELLS 149`, `band_cell`) live here and `band.rs` re-exports them. Ultrawide numbers: canvas 2560×720, core 800, wing 422..800, viewport 800..1760, right column 1760..2080, band 422..2080 with 275 log cells, minimap at (1792, 8).
- `layout.rs` is the core (unchanged constants, `VIEWPORT` at (0,0)); `Rect::shifted`; `Fit { scale, width, offset }` with `width = max(1280, physical.0 / scale)`; `physical_to_canvas` clamps to `fit.width`; `canvas_translation` centres on it. `fit((5120,1440)) = {2, 2560, (0,0)}`, `(7680,2160) = {3, 2560}`, `(3840,2160) = {3, 1280}`, `(1920,1080) = {1, 1920, (0,180)}`, `(3440,1440) = {2, 1720}`.
- Painting: `Raster.origin` is added in `set` only (`get`, `fingerprint`, `rgba` are canvas space); `erase(rect)`, `reset(w, h)`; `Frame::within(origin, paint)` restores `(0,0)`; `Frame::push(widget)` shifts rect and arrows; `outline` asserts origin off. `screen::compose_into(frame, layout, view, hover, pressed)`: reset, `backdrop` (fill canvas, erase viewport and minimap), `within(layout.core, core painters)`, `band::band(frame, layout, view)`, outline. `compose` = narrow; `compose_in(layout, …)`; dumps write `<name>-wide.ppm` at 2560.
- Render side: `CursorPlugin` owns `Res<Layout>`, synced at the end of `track_window` from `size.fit().width` (from the resource, so a test's `insert_resource(WindowSize)` counts). `viewport::canvas_to_world(width, x, y, z)`; `Spawner { commands, server, images, width }.spawn::<M>(ops, origin, z)`; `redraw` also runs on `layout.is_changed()` and spawns the scene at `layout.core`, the automaps at `layout.minimap()` / `overlay_clip()`. `pixel::fit_canvas` (after `UiSet::Cursor`) resizes the canvas target with `Image::resize` when `image.width() != fit.width`; `ui::upload` resizes the UI image (resize first, then assign data) and moves the `UiSprite` to `canvas_to_world(width, 0, 0, UI_Z)`.
