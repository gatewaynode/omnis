# Acceptance: the seal (M8.5 7h1)

This is the script for accepting M8.5 sub-step 7h1, the first of 7h (saves by name; the plan's re-scope is at
the top of `tasks/plans/m8.5-saves-by-name.md`).
- Every `pack.ron` now records `hash`: the hash of the pack's content at its version.
- The loader refuses a pack that is not sealed, or whose content changed since it was sealed. So content never
  changes under one version, and a save made on a version names exactly that content.
- `omnis-cli pack seal` records the hash. A changed pack goes up a patch number.

**What moved:**
- Every pack's fingerprint changed once, so both golden replays were rebaselined. Only their pack hashes and
  fingerprints moved; not one command did.
- As you chose, saves made before 7h now count as made with other packs. The window refuses them; the socket
  and CLI can still force them.

## Steps
1. Copy the test pack: `cp -R packs/test /tmp/omnis-test`. Add a line `// edited` at the end of
   `/tmp/omnis-test/data/maps/town.ron`. Run `just run --windowed --pack packs/base --pack /tmp/omnis-test`.
   *You will see* the game exit with "the content changed since version 0.1.0 was sealed: raise the version
   and reseal with `omnis-cli pack seal`".
2. Run `cargo run -q -p omnis-cli -- pack seal /tmp/omnis-test`.
   *You will see* "sealed at 0.1.1, hash …". `/tmp/omnis-test/pack.ron` reads `version: "0.1.1"` and a
   `hash:` line, with its comments kept.
3. Run the game again as in step 1.
   *You will see* the title screen.
4. Run the seal again.
   *You will see* "already sealed at 0.1.1", and `pack.ron` unchanged.
5. Optional: `cargo run -q -p omnis-cli -- pack seal /tmp/omnis-test --version 0.2.0`.
   *You will see* "sealed at 0.2.0".

## What the tests cover
- **`omnis-data/tests/seal.rs` (4):**
  - an unsealed pack is refused, sealing it lets it load, and its comments are kept;
  - a changed pack is refused until resealed at the next patch number, and a version given is written;
  - comments and layout in `pack.ron` are not content;
  - the shipped packs are sealed.
- **The tests that write packs on disk** seal them: `round_trip`, `flags` and `bad_packs`.
- **Mutations (6 of 6 caught):**
  - the check skipped;
  - the hash covering its own field;
  - the manifest hashed as raw text;
  - changed content accepted;
  - no patch bump;
  - the version not hashed again.
