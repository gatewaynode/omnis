# Acceptance: retiring `omnis-app` (parity P9)

This is the script for accepting parity step P9 (`tasks/plans/p9.md`). The old client, `omnis-app`, is gone from the
workspace, and `omnis-vector` is the only client and builds the binary `omnis`. Built to your answers of 2026-10-11:
- Look and Map go to the backlog.
- The binary is `omnis`; the crate stays `omnis-vector`.
- Of the old flags only `--frame-stats` comes across.
- ARCHITECTURE.md and PRD.md are edited, with the decision records marked rather than rewritten.

The clock line's date (found during P9) is in the backlog too.

## Part 1: the game
1. Run `just run --windowed`.
   *You will see* the title in a window called "Omnis": "New game", "Load quick save", "Settings", "Quit".
2. Run `just run-app`.
   *You will see* just say there is no such recipe.
3. Run `cargo build -p omnis-vector`.
   *You will see* `target/debug/omnis`, and no `target/debug/omnis-vector` built from now on (an old one may still
   be there from before).
4. Run `just run --windowed --frame-stats`, start a new game and walk.
   *You will see* the terminal print `fps` and `frame_time` lines about once a second, with vsync off. This one is
   yours: an agent's window draws no frames.
   Covered by `shell::session::tests::frame_stats_log_the_frame_times_with_vsync_off`.
5. Start the game with a pack that is not there: `just run --pack no/such/pack`.
   *You will see* `omnis:` and a message that names `no/such/pack`, and the game does not start.
   Covered by `tests/game_io.rs::a_missing_pack_stops_the_start_with_its_name`.

## Part 2: the MCP bridge
1. With the game running from Part 1 (in a game), ask me for `game_status` over MCP.
   *You will see* the status of your game: the bridge found it through `.omnis/dev.addr`, as before.
2. Ask me for a `screenshot`.
   *You will see* what your window shows.

Covered by `tests/socket.rs::a_client_drives_the_vector_client_over_loopback`, which now also creates a member
and sets a rule over the socket. The rule shows in the views, and the session stops replaying.
