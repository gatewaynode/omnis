# Acceptance: the vector client reads views (P0) and hosts the dev socket (P1)

The script for your acceptance of parity steps P0 and P1 (`tasks/plans/p0-p1.md`). P0 changes nothing
you can see: the client now reads the world only through the engine's views. P1 lets the MCP bridge drive
and capture the vector client. The live capture could not be checked from the agent's session: a window
started there gets no connection to the window server and runs no frames (both clients), so Part 2 is
the first time it runs.

## Part 1: the game as before
1. `just run --windowed`.
   *You will see* the town as before: `test:map:town  cell (10, 2) facing West`, `refusals 0
   disagreements 0`, the minimap top right.
2. Open the guild door and step in, Leave, walk out to the meadow, and fight whatever finds you.
   *You will see* everything as in the vector adoption's acceptance (`tasks/acceptance/vector-adoption.md`):
   the door, the town notice, the fight screen, End turn, the roll log naming members and spells.
   Covered by `omnis-vector/tests/shell.rs::the_views_are_the_world_s_after_every_frame` and the rest of
   vector's tests.

## Part 2: the dev socket, with the game from Part 1 still running
1. In Claude Code, with the `omnis` MCP server connected, ask for `game_status`.
   *You will see* the party's place, `test:map:town` and its cell.
2. Ask for `sim_command` with `{"Step": "Forward"}`.
   *You will see* the party step in the window, the HUD line `Moved to ...`, and the command count
   go up by one.
3. Ask for `screenshot` (either target).
   *You will see* the window hold still for a few frames, then the reply image: the 3D view with the
   HUD, the buttons and the minimap, as the window shows it.
4. Ask for `screen_text`.
   *You will see* one line per text on screen: the HUD, and the buttons marked `[button]`.
5. Ask for `save_write` to `saves/p1.ron`, then press **Save log** in the window.
   *You will see* the log saved. Then `save_read` the same file and press **Save log** again:
   *You will see* the HUD say the log no longer replays, naming the save.
   Covered by `omnis-vector/tests/socket.rs::a_client_drives_the_vector_client_over_loopback` (headless,
   all but the image).
