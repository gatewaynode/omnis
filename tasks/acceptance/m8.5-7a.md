# Acceptance: the journal and its measurement (M8.5 7a)

This is the script for accepting M8.5 sub-step 7a (`tasks/plans/m8.5-save-model.md`). It is the first piece of
the save model (PRD D28): the engine keeps the journal, every command it accepted since the world's base, each
stamped with the party's age after it. The journal is what a character save will carry and a load will replay
(7d). Nothing is saved differently yet: saves, fingerprints and the replays are unchanged.

What 7a measures is what a load by replay would cost:
- how long a command takes to replay;
- how many bytes an entry takes;
- how many commands an hour of play makes.

Those numbers size the provisional fold (7e).

**Departures and choices of mine:**
- **Events are measured, not kept.** The approved plan had each entry keep its events for the archive. That is
  moved to 7e, where the archive is built and read. 7a only measures their size, so keeping them now would cost
  memory with no reader.
- **The journal is not saved yet.** So a load starts it again at 0, and the debug page says "since the start or
  the last load". 7d puts it in the character save.
- **Dev commands are journaled.** A replay must repeat them like any other command.
- **The timing is this machine's, this session's.** The debug page divides the time the accepted commands took
  by their count, and replay is the same work.
- **Commands an hour counts menus and pauses.** It is wall time since the first command.

**Start.** Run `just run --windowed --pack packs/base --pack packs/test`, then start a new game with devtools on and
make a party.

## Part 1: the journal on the debug page
1. Press Esc, then Debug, then the World page.
   *You will see*, under the teleport controls, three dim lines:
   - "Journal: N commands since the start or the last load", where N counts the party's creation, one per
     member;
   - "Replay would take about 0 ms (U µs a command, measured this session)";
   - "Commands an hour: after a minute of play".
2. Close the panel. Walk ten cells in the open and turn left twice with the keys, then reopen the World page.
   *You will see* the journal up by twelve: one per cell crossed and one per quarter turn. Walking into a wall
   adds nothing, because the client holds the step before it reaches the engine.
3. Play for more than a minute (walk, open a door, fight if something comes), then reopen the page.
   *You will see* "About K commands an hour of play this session (menus and pauses count)". **Please tell me K
   after a normal stretch of play: it sizes the provisional fold.**
4. Save on the pause screen, load the save, and reopen the page.
   *You will see* "Journal: 0 commands …". This is expected until 7d. The timing lines keep this session's
   figures.

## Part 2: the measurement in a terminal
5. Run `cargo run --release -p omnis-cli -- wander --commands 10000 --out .omnis/wander.ron`.
   *You will see* "wrote 10000 commands to .omnis/wander.ron", then the events' bytes a command, the maps
   walked, the fights and the minutes lived. The wanderer is a seeded party of four that:
   - steps, turns, uses and searches at random;
   - fights what it meets;
   - rests when hurt;
   - teleports every 1,000 commands, so it walks every map.
6. Run `cargo run --release -p omnis-cli -- replay .omnis/wander.ron --time`.
   *You will see*:
   - "ok: 10000 commands reproduce fingerprint …";
   - the replay's milliseconds and µs a command;
   - the bytes a journal entry takes.
7. (Optional) Pause, then Save log, writes `.omnis/vector-session.ron`. Then
   `cargo run --release -p omnis-cli -- replay .omnis/vector-session.ron --time` times your own session's
   commands. A session that loaded a save cannot be saved as a log; that refusal is the old one.

## What the tests cover
- Each accepted command adds one entry with the party's age after it; a refused one adds nothing; a dev command
  is an entry; a new or loaded world starts empty; the save text and fingerprint do not change; a replay of
  both goldens rebuilds the played journal exactly. Covered by `omnis-sim/tests/journal.rs`.
- The wanderer is seeded, reproduces its fingerprint, walks several maps and fights. Covered by
  `omnis-cli/tests/wander.rs`. `wander` and `replay --time` print their lines, covered by
  `tests/cli.rs` (`wander_writes_a_replay_that_replay_times`).
- The World page counts the journal and prices the replay, covered by `omnis-vector/tests/debug.rs`. The timing
  arithmetic is covered by `tests/binding.rs`.
- The measurement itself is an ignored test:
  `cargo test --release -p omnis-cli --test integration journal_timing -- --ignored --nocapture`.
