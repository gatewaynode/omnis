# Acceptance: whose a flag is (M8.5 7c)

This is the script for accepting M8.5 sub-step 7c (`tasks/plans/m8.5-save-model.md`), the third piece of the save
model (PRD D28 and §7.7). A pack now says whose each flag is:
- **a party flag** (a quest taken, an oath, a debt) travels with the party in its character save;
- **a world flag** (a bridge burned, a lord dead) stays with the world and folds with it.

The world's split (7b) now puts each flag in its owner's part. Saves are unchanged.

**Your answer (2026-10-17):** both, declared per flag, and a flag no file declares is the world's.

**Choices of mine:**
- **One file per flag.** A flag is declared in `data/flags/<name>.ron` as `(schema: 1, id: "pack:flag:name",
  scope: Party)`. Leaving the scope out means World, so a file is needed only to make a flag the party's. The
  lever's file declares World only as an example. A misspelt field is refused rather than read as the default.
- **Existing flags keep their numbers.** Declared flags are numbered after the ones objects already name, so a
  save holding the lever's flag reads the same.
- **A declared flag exists before anything sets it**, so the debug panel can set it.
- **The test pack carries the examples.** The objects pack gains `objects:flag:debt` (the party's; nothing sets
  it but the panel) and declares the lever's flag as the world's. The shipped base and test packs have no
  flags, and are unchanged.

**Start.** Run `just run --windowed --pack packs/base --pack packs/test --pack crates/omnis-sim/tests/packs/objects`,
then start a new game with devtools on and make a party.

## Steps
1. Press Esc, then Debug, then the World page, and step the Flag choice.
   *You will see* "objects:flag:lever (world, now 0)" and "objects:flag:debt (party, now 0)".
2. Choose the debt, type 2 in Value, and press Set.
   *You will see* "objects:flag:debt (party, now 2)".
3. Press Split.
   *You will see* "Flags set: 1 the party's, 0 the world's", and "Round trip: ok".
4. Teleport to `objects:map:yard`, pull the lever (Use on it), reopen the World page, and press Split.
   *You will see* "Flags set: 1 the party's, 1 the world's" and "Round trip: ok". The yard's region is among
   the lines.
5. In a terminal, run `cargo run -p omnis-cli -- schema dump | grep -A6 'data/flags'`.
   *You will see* the flag file's example.

## What the tests cover
- `omnis-data/tests/flags.rs`:
  - the objects pack declares the debt as the party's and the lever as the world's;
  - the lever keeps flag number 0;
  - a file without a scope, and a flag no file declares, are the world's;
  - a wrong id type, a later schema and an unknown scope are refused.
- `omnis-sim/tests/split.rs`: the party's flag goes in the checkpoint, the world's and an undeclared one in
  the world base; the round trip holds; the report counts 1 and 2; a flag in both parts is refused.
- `omnis-vector/tests/debug.rs`: the Flag choice names each flag's owner, and Split counts them.
- `omnis-cli/tests/cli.rs`: the schema dump has the flags section.
