# Acceptance: elevation in the map format (M8.5 step 1a)

This is the script for accepting M8.5 step 1a (`tasks/plans/m8.5-elevation.md`), built to your answers of
2026-10-12:
- **Height:** per cell, in eighths of a cell (a wall is 8 tall), with ramp edges.
- **Climb:** an allowance per terrain, set by the terrain entered and limiting drops too.
- **Ramps:** up to 16.
- **Sight:** hills hide, and height extends how far you see.

The game does not draw height yet; that is step 4. So this script checks the rules: what refuses, what is
seen, and that the shipped maps are untouched.

The fixture map is `heights:map:hills`, in `crates/omnis-sim/tests/packs/heights` (not shipped). Grass
allows 2, scree 1, stairs 4. Its heights:

```text
      x: 0  1  2  3  4  5  6  7  8
y 0:     0  2  4 12 12 12 12 12 12    a slope, then a cliff up to 12
y 1:     0  3  3  3  3  3  3  3  3    scree at 0, stairs at 3: one way
y 2:     0 16 16 16 16 16 16 16 16    a ramp "/" between x 0 and 1
y 3:     0  0  0  0  0  0  0  0  0
y 4:     0  0 16  0  0  0  0  0  0    a hill at x 2; a wall between x 3 and 4
```

## Part 1: in the window
1. Run `just run --windowed --pack packs/base --pack packs/test --pack crates/omnis-sim/tests/packs/heights`.
   Start a new game.
2. Open the debug panel (Esc, then Debug), go to Page "World" and step Map to `heights:map:hills`. Set x 0,
   y 0, Facing east, and click Go. Close the panel.
3. Walk east.
   *You will see* two steps taken (the slope 0, 2, 4) and the third held, with "Blocked: too steep" on the
   message line and once among the HUD's lines, however long you push. Let go and push again for it once
   more. The ground still looks flat; drawing it is step 4.
4. Go to (0, 1) facing east with the debug panel, and walk east.
   *You will see* the step onto the stairs taken. Turn around and walk back.
   *You will see* "Blocked: too steep": the scree allows only 1.
5. Go to (0, 2) facing east, and walk east and back.
   *You will see* both steps taken: the ramp crosses 16.
6. Quit, and run `just run --windowed` with no packs named.
   *You will see* the town, meadow and dungeon play as before. Casting Light in the dungeon now lifts the fog
   in the view as far as the light reaches (8 tiles). Before, the fog stayed at the floor's 6.

Covered by `crates/omnis-sim/tests/elevation.rs` (the slope, the cliff, one way, the ramp),
`omnis-vector/tests/agreement.rs::the_mirror_agrees_on_cliffs_and_ramps`,
`binding.rs::pressing_on_a_cliff_names_it_once_per_contact`,
`message.rs::walking_into_a_cliff_says_it_is_too_steep_once` and
`tests/cast.rs::a_light_lifts_the_fog_with_the_engine_s_sight`.

## Part 2: over MCP (headless), what is seen
1. Start the bridge headless on the fixture:
   `target/debug/omnis-mcp --headless --pack packs/base --pack packs/test --pack crates/omnis-sim/tests/packs/heights`.
   Create a party member with `party_create`, as in earlier scripts. Then place the party with `sim_command`
   `{"Dev": {"Teleport": {"map": "heights:map:hills", "x": 0, "y": 4, "facing": "East"}}}` (headless worlds
   have devtools on).
2. `viewport_get`.
   *You will see* `visibility_depth` 6 and the tile (2, 4) with `height` 16. No tile with x 3 or more in row
   4: the hill hides them.
3. Teleport to (2, 4) facing east, and `viewport_get` again.
   *You will see* `visibility_depth` 8: 16 above the lowest tile around, so two more tiles. Tiles (6, 4),
   (7, 4) and (8, 4) are listed, seen over the wall. (3, 4), right below the hill's edge, is not.
4. `map_text`.
   *You will see* the row `|g/g g g g g g g g|` with the ramp.

Covered by `elevation.rs::a_hill_hides_the_ground_behind_it_and_the_hilltop_sees_over_a_wall`,
`standing_high_sees_farther_by_the_rule_s_rise` and `map_text_draws_a_ramp`.

## Not in this script
- Every pair of tiles on every shipped map sees exactly as before:
  `elevation.rs::on_the_flat_maps_sight_is_what_it_was_for_every_pair_of_tiles`.
- A bad heights row, a height out of range, a ramp on the boundary or over 16, and `/` as a terrain glyph are
  refused when the pack loads, each with its message. Covered by the `map.rs` unit tests and the broken
  pack.
