This is an turn based open world RPG inspired heavily by the classic 1980's games Might and Magic I & II.  The intent of this game is build on the open world style of the game with modern convieniences, an ecosystem and environment engine, a story building engine, and wider PC and NPC building and advancement.  From the ground up the game intends to have the environemnt editing and content management systems necessary to support extremely complex world features and stories.  The game world will also support 100% procedural generation, so that vast areas can be created and then left as is or customized.
